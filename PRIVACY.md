# Privacy

`dsh-skill-pack-security` is a local DeepSeek Harness maintenance/documentation surface.

- It reads the repository files and configuration needed for its documented purpose.
- It adds no telemetry, analytics, advertising or hosted account, and sends no data to PerryLink.
- It writes no data outside the workspace and the user's DSH profile; the host controls its own logs and retention.
- Removing the repository or package removes its code; it does not delete host logs or workspace files.

This statement covers this repository, not the DSH host.
